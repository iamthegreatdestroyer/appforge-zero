## Component Sequence — WS Auth & Presence

```mermaid
sequenceDiagram
  participant User
  participant WS
  participant Auth
  participant Redis
  participant Events

  User->>WS: Open WebSocket + send JWT
  WS->>Auth: Verify JWT (JTI, expiry)
  Auth-->>WS: OK (userId)
  WS->>Redis: Add presence(userId, connId)
  WS->>Events: Publish user.connected event
  Note right of Events: Notification/Analytics consumers process
```
